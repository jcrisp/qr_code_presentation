Takeaways

  • Pick the smallest gem that does the job — not the most capable one.
  • An output format is an architecture decision. Choosing SVG over PNG deleted a dependency, scaled for free, and made the code testable.
  • Unused code still ships. An image parser you never call is attack surface with no benefit.
  • A fork is a fair price when the patch is small and mechanical — and a bad one when it isn't.
  • Test the failure that will actually happen, not the one that's most impressive to test.
