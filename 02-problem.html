The problem

RiskAssess keeps a school's Hazardous Chemicals Register — a legally required list of what's stored where.

  • Emergency services need it at the door, on a phone, with no login.
  • Schools print an Entire School code for the front desk, and a per-room code for each storeroom door.
  • Scanning opens a public, share-code URL straight to that location's register.
  • A second code on the stocktake screen lets a teacher hop from desktop to phone mid-count and walk into the store.

So: generate a QR code from a URL, server side, render it in a page that prints well — and be confident it isn't blank.
