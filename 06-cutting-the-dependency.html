Cutting the dependency

We render SVG. So the PNG renderer — and the image library behind it — is code we ship, never call, and can still be attacked through.

  • Image libraries are a classic memory-safety target: they parse untrusted binary, and decoders have a long CVE history.
  • Loaded code is reachable code. An unused dependency is pure risk with no upside.
  • So I had Codex strip the PNG path out of rqrcode and drop the library from the gemspec. Small, mechanical, easy to review.

The trade: carrying a fork costs real maintenance — track upstream, re-apply on every bump. Worth it when the patch is small and the payoff is a smaller security surface. It would not be worth it for a sprawling change you'd have to rebase forever.
