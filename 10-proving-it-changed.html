Proving it changed

Picking a location has to regenerate a different code. You can check that without decoding either one.

share_spec.rb

school_qr = find(".qr_svg svg path")[:d] # the entire-school QR

select "Building 4 - Chemical store", from: "location"

assert_qr_rendered(".qr_svg svg")                        # still a valid QR...
expect(find(".qr_svg svg path")[:d]).not_to eq school_qr # ...encoding a different URL

The path data is the module grid. If the URL changed, the path changed. That's use_path: true paying rent a second time.
