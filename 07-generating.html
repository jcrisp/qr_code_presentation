Generating the code

share_controller.rb

require 'rqrcode'

@share_url = "https://jamescrisp.org"
@qr_svg = RQRCode::QRCode.new(@share_url).as_svg(viewbox: true, use_path: true)

share.html.haml

.qr_svg= raw @qr_svg
  • viewbox: true — no fixed width, so one SVG scales to the 250px box on screen and the 350px poster in print. CSS decides the size.
  • use_path: true — one <path> instead of several hundred <rect> elements.

Three lines, no files on disk, no image processing. Hold on to those two flags — they're what makes the test on the next slides possible.
